# File Organiser

A simple Python script that automatically organizes files in a folder by their extension.

## Features

- Creates folders automatically (Images, Documents, Videos, etc.)
- Moves files based on their extension
- Skips files without extensions
- Simple and easy to use

```text

│   └── photo.jpg
├── Documents/
