# System Info Reporter

A simple Python script that displays basic system information in the terminal.

## Features

- Shows current date and time
- Displays operating system name
- Shows processor architecture
- Displays total and available RAM
- Shows disk usage

## Requirements

- Python 3.x
- `psutil` library

## Installation

```bash
pip install psutil
